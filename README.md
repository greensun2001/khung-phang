# Tính khung phẳng BTCT

Công cụ web tĩnh phân tích khung phẳng (cột, dầm bê tông cốt thép) bằng phương pháp độ cứng trực tiếp: biểu đồ M, Q, N, biến dạng và báo cáo tính toán. Vật liệu mặc định theo EN 1992-1-1 (cột C30/37, dầm C40/50).

Mở `index.html` trong trình duyệt hoặc truy cập trang GitHub Pages của repo này.
